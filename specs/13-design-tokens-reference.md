# 13 — Design Token Reference (locked values + measured ratios)

Resolves the [00] open item. All ratios are WCAG 2.1 relative-luminance, computed (not estimated). These are the canonical default values; consumers override any via CSS vars.

## 13.2 Measured contrast ratios (the AA proof for §3.4)

| Pair | Ratio | WCAG |
|------|-------|------|
| `--glass-fg` `#111113` on plate `#FFFFFF` | **18.9 : 1** | AAA |
| `--glass-fg-muted` `#6E6E73` on plate `#FFFFFF` | **5.1 : 1** | AA |
| `--glass-fg` `#F5F5F7` on plate `#1C1C1E` | **15.8 : 1** | AAA |
| `--glass-fg-muted` `#AAAAB0` on plate `#1C1C1E` | **7.4 : 1** | AAA |
| white text on `--glass-tone-primary` `#0A84FF` | 3.6 : 1 | **large text only** |
| white text on aa primary `#0066CC` | **5.6 : 1** | AA |
| white text on `--glass-tone-destructive` `#FF453A` | 3.4 : 1 | **large text only** |
| white text on aa destructive `#CC2A20` | **5.4 : 1** | AA |

Rule baked into tokens: in `contrast="aa"`, tone accents swap to their darkened variants (set in `[data-lg-contrast="aa"]` block, [02 §2.1]) so any text on a tone fill passes AA at normal size. Outside aa mode, primary/destructive **fills** are used for ≥18.66px-bold/≥24px text or paired with `plate` for small text.

## 13.5 Token governance

Every token here is **public API**. Changesets policy: add = `minor`, rename/remove/semantic-change = `major`. A generated `tokens.md` (built from `tokens.css` + a measured-ratio script) is the published source of truth; this file is the design intent. The ratio column is regenerated by the contrast tooling ([09 §9.3]) so it can't drift from the actual hexes.
